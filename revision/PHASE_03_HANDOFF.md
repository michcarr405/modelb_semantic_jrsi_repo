## 2. What Phase 3 established

### Statistical unit and nesting

- The independently evolved baseline population is the sole inferential unit.
- One information–viability frontier is constructed per baseline replicate.
- Grouping maps are nested repeated measurements.
- Continuation seeds are technical replicates nested within map and baseline replicate.
- Exact duplicate map aliases are collapsed; conflicting duplicates are rejected.
- Every reported independent `n` is derived from baseline blocks, not maps or continuations.

### Paired continuation handling

- Purpose-separated observation and propagation streams are keyed by root seed, baseline replicate, and continuation index.
- Map identity is excluded from the stream key to implement common random numbers across actual and intervened continuations.
- Actual and identity endpoints recover identical trajectories when their model inputs are identical.
- A tiny model diagnostic produced zero actual–identity trajectory difference and identical final populations.

### Frontier and target handling

- Map-level viability is averaged across nested continuation seeds before frontier construction.
- Frontiers use measured retained information, not nominal group count.
- The primary validated frontier is a discrete monotone upper envelope with no binning, smoothing, or interpolation.
- Target detection returns the smallest tested information coordinate reaching the target.
- Target-not-reached cases return `semantic_information = NaN` and a separate right-censored lower bound.
- Machine-readable counts report independent replicates, target-reaching replicates, censored replicates, and reaching fraction.

### Bootstrap and permutation inference

- Complete baseline-replicate blocks are resampled, stratified by condition.
- Censored semantic values are never imputed.
- Semantic intervals are explicitly conditional on reached cases; censored lower bounds are summarized separately.
- Replicate-level permutation tests reject duplicate baseline rows and reject silent complete-case testing of censored semantic estimates.
- Unpaired exact/Monte Carlo label permutation and paired sign-flip permutation are implemented with dedicated streams.

### Continuation variance

- A diagnostic now quantifies stability as the number of continuation seeds increases.
- This supplies the evidence mechanism needed to resolve P02, but Phase 3 does not choose the production continuation count.
