## 3. Phase 4 performance implementation

The production branch vectorizes the already-audited compositional-resampling transition. The stochastic law is unchanged:

1. each daughter samples one parent in proportion to fitness;
2. each daughter slot independently chooses parent-derived or environmental sequence identity;
3. parent-derived identities are sampled with replacement;
4. environmental sequences are uniform over the four-symbol alphabet;
5. every site mutates independently.

All random arrays are generated by the caller-supplied explicit generator. This removes Python-loop runtime without introducing hidden RNG state. It changes deterministic draw ordering relative to the historical implementation but not the transition distribution. Same-seed determinism, different-seed divergence, extreme parent/environment cases, and all Phase 3 identity tests pass.

## 7. Information and frontier validation in production

Every baseline has one stored observation used for:

- total information `I(M;Z)`;
- positional information `I(M;S)`;
- conditional information `I(M;Z|S)`;
- a 200-permutation within-segment correction.

Every map uses actual retained information `I(g(M);Z|S)`. The constant and identity endpoints are explicit. One discrete monotone frontier is constructed per independently evolved baseline. No binning, smoothing, or interpolation is used.

## 8. Bootstrap and permutation inference

The production block bootstrap samples the already-constructed one-row-per-baseline frontier summaries with replacement, stratified by condition. Because each frontier is computed wholly within one baseline block before resampling, this is mathematically equivalent to resampling complete raw blocks and reconstructing their unchanged frontiers, while avoiding repeated recomputation. Censored values are never imputed.

Production settings:

- 2,000 bootstrap draws per fidelity;
- 9,999 Monte Carlo replicate-label permutations where exact enumeration is infeasible;
- independent evolved baseline population is the only inferential unit.
