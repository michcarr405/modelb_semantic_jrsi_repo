# Release notes — JRSI Round-2 reproducibility release v2.0.0

This release supports the Round-2 major revision of manuscript **rsif-2026-0516**, *Counterfactual interventions reveal causal relevance of inherited sequence distinctions in a compositional-resampling model*.

## Principal Round-2 changes

- The primary causal intervention is now the population-frequency-weighted, probability-space marginal-preserving (MP) grouping intervention.
- Retained-information coordinates are permutation-corrected consistently at every grouping-map coordinate.
- The primary information/fitness result is a graded, intervention-specific relationship between corrected retained sequence-specific organization and normalized future-fitness recovery.
- The first-99%-recovery crossing is retained only as a secondary diagnostic.
- Six causal-specificity contrasts are archived, with five passing the frozen multiplicity rule and the acute default topology-mismatch contrast retained as borderline.
- Stage A/B1/B2 were expanded to n=8 per setting and retained as replicated screening/domain mapping.
- Stage C uses n=8 per variant.
- Stage D uses n=8 independently evolved populations per nondefault confirmation.
- Independent affinity generality uses eight independently generated affinity landscapes as top-level inferential units, with eight nested populations per landscape-setting cell.
- Reviewer-requested expected and empirical P(Z|S), adjacency, and fitness diagnostics are archived.
