## 2. Focused scope

All confirmatory Phase 5 controls are restricted to the Gate 4 primary transmission fidelity, `p = 1.0`, with 20 matched evolutionary seed blocks. This is a causal-specificity phase, not a parameter-sensitivity phase.

The Phase 4 native/full-selection result is read directly from the archived Phase 4 outputs. New simulation is limited to the prespecified controls below.

## 3. Selection-strength controls

Parent probabilities are defined by

\[
\pi_i(\alpha)
=
(1-\alpha)\frac{1}{N}
+
\alpha\frac{F_i}{\sum_j F_j}.
\]

The controls are:

- neutral propagation: `alpha = 0.0`;
- reduced selection: `alpha = 0.25`;
- full selection reference: `alpha = 1.0`, read from the Phase 4 archive.

Neutral and reduced-selection populations use the same initial-population, observation, and propagation random streams as their matched Phase 4 replicate. Their continuations retain the same selection strength used during evolution.

## 4. Complete affinity-profile reassignment

For each archived Phase 4 selective `p = 1.0` population, run two nested complete profile reassignments. Each reassignment is a deterministic random derangement of all 1,024 motif identities, so every complete four-state affinity vector is transferred to a different motif identity while the profile multiset is preserved exactly.

The fixed D20 grouping maps are not regenerated. Information coordinates are re-observed under the reassigned channel, and actual/intervened continuations use paired random streams.

## 5. Fitness-map mismatch

Matched fitness topologies preserve:

- four symmetric fitness-promoting off-diagonal unordered pairs;
- one symmetric fitness-reducing off-diagonal unordered pair;
- one symmetric fitness-neutral off-diagonal unordered pair;
- all four diagonal pairs as fitness-reducing;
- the Phase 4 reward, penalty, and floor.

For each archived native population, evaluate two nested, independently keyed non-native matched topologies. The native topology is excluded. The two mismatch realizations are averaged only after a separate frontier is constructed for each realization.

## 6. Alternative stable topologies

Enumerate the complete matched-topology universe. Select two fixed non-native topologies without using simulation outcomes:

1. topology A maximizes categorical Hamming distance from the native topology, with lexicographic tie-breaking;
2. topology B maximizes its minimum categorical Hamming distance from both the native topology and topology A, with lexicographic tie-breaking.

Twenty populations are evolved under each stable topology using matched Phase 4 seed blocks. Each evolved population is evaluated under its native topology and the other stable topology. The replicate-level native advantage is the mean of the A and B native-minus-nonnative differences within each matched seed block.

## 7. Temporally unstable topology null

For each matched seed block, evolve one population while redrawing a topology from the same matched universe at every generation, without immediate repetition. The topology schedule is generated by a dedicated stream and is shared across actual and intervened trajectories within a continuation.

The fixed-topology reference is the within-seed mean of the native evaluations for stable topologies A and B.

## 8. Analysis hierarchy

The independently evolved seed block is the only inferential unit. Control realizations, grouping maps, and continuation seeds are nested technical measurements.

For each control realization:

1. observe baseline conditional information;
2. apply the unchanged 34-map panel;
3. average two continuation seeds within each map;
4. build one discrete monotone frontier;
5. retain explicit target reach and right-censoring.

For controls with two disruption realizations, frontiers are constructed separately and only then aggregated to one seed-block record. Censored semantic estimates are never imputed.

## 9. Primary Gate 5 metric and contrasts

The primary always-defined metric is value of information,

\[
\Delta V = V_{\mathrm{actual}} - V_{\mathrm{constant}}.
\]

The six prespecified paired contrasts are:

1. full selection minus neutral selection;
2. full selection minus reduced selection;
3. native mapping minus complete affinity-profile reassignment;
4. native topology minus matched topology mismatch;
5. alternative stable-topology native evaluation minus non-native evaluation;
6. stable fixed-topology native evaluation minus the temporally unstable null.

Each contrast uses a paired replicate-level randomization test on 20 seed-block differences. Two-sided p-values are Benjamini–Hochberg adjusted across the six contrasts. A contrast passes only when its mean difference is positive and `q < 0.05`.

**Gate 5 passes only if all six contrasts pass**, all identity endpoints recover exactly, all control datasets retain explicit censoring, and no archived Phase 4 state or core output changes.

Semantic-information estimates and target-reaching fractions are secondary descriptive outcomes because Phase 4 showed that the strict target was reached only at identity in selective populations.
