# Reproducibility gap audit

## Closed now
- Exact five integrated MP-migration driver scripts recovered from the scientific freeze.
- Deterministic stream specifications recovered for all seed roots/purposes visible in those drivers.
- Independent-affinity campaign: all 256 evolved populations regenerated and checked against the frozen population-state hashes; all eight base affinity landscapes regenerated.
- Frozen compact source tables and prespec/freeze records are bundled.

## Blocking gaps
### A. Missing exact MP operator module
The exact drivers for core/screen, Stage C and Stage D import `modelb_semantic_repo.mp_operator`. No exact copy is present in the currently mounted R2 scientific-freeze ZIP, the transferred Round-1 Gate-8 archive, or current public repository state. A functionally reconstructed module would need to be clearly labelled as reconstruction and validated against all frozen outputs; it cannot silently be called the original production source.

### B. Missing exact high-continuation causal-specificity production archive
Prior project provenance records the package name `JRSI_R2_HIGH_CONTINUATION_MP_CAUSAL_SPECIFICITY_2026-10-02.zip`, prespec commit `a00e82002fd60774927e32ad8658692c243edfa8`, and result commit `2af49c5c8a9ae491928439dc056bfb1f65368102`. The campaign used 64 new continuation streams/evaluation (indices 2–65), 20 seed blocks, 36 generations and 15,360 continuation-level evaluations. The exact driver, root seed and original raw table are not present in the currently mounted files. Downstream Figure-5 recovered source/QC does not establish raw regeneration.

## Claim discipline
Until A and B are closed, the correct statement is: **the Round-2 MP evidence is extensively archived and the independent-landscape campaign is state-level reproducible, but full end-to-end regeneration of every MP-primary source table has not yet been demonstrated from the assembled release candidate.**
