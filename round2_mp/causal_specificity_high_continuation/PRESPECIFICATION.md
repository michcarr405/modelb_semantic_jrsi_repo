**Manuscript:** rsif-2026-0516.R1

**Date frozen:** 2026-10-02

## 1. Motivation and status

The first Round-2 marginal-preserving rerun used the exact historical two-continuation design and found that five of six historical contrasts passed the unchanged Gate-5 criterion, whereas native topology minus matched topology mismatch remained positive on average but did not pass inference. Because that result was already observed, the present campaign is a **prospectively specified precision/replication campaign**, not an outcome-naive first confirmatory test.

To avoid selectively attempting to rescue the one failed contrast, **all six contrasts are rerun together under one fixed higher-continuation design**. No contrast-specific sample size, stopping rule, seed rule, or analysis rule is permitted.

## 3. New continuation replication plan

The primary analysis uses **64 entirely new continuation indices per evaluation realization**, fixed as indices `2..65` inclusive. Historical indices `0` and `1` are excluded from the primary high-precision estimate because their outcomes have already been inspected.

The new streams extend the original deterministic continuation protocol:

- continuation root seed: `2026073104` (historical Phase-4 continuation root);
- pairing key: the exact archived `pairing_baseline_replicate`;
- continuation indices: `2..65`;
- both actual and marginal-preserving branches use separately instantiated generators with the **same stream key**, preserving matched common random numbers.

There is **no sequential stopping**. All 64 new continuations are run for every one of the 240 evaluation realizations.

For the temporally unstable condition, each new continuation receives a new 36-generation topology schedule generated by the **historical Phase-5 schedule generator and seed protocol**:

- topology-schedule root seed: `2026073105`;
- purpose: `phase5-unstable-topology-continuation`;
- keys: `(pairing_baseline_replicate, continuation_index)`;
- continuation indices: `2..65`;
- no immediate topology repetition, exactly as in the historical generator.

Actual and marginal-preserving branches share the same topology schedule within each continuation.

## 4. Intervention

For the evaluation affinity matrix of each realization, define the native local-state probability kernel

`P0(z|m,s) = softmax((a_mz + beta 1[z=f(s)]) / Theta)`.

At every continuation generation `t`, the marginal-preserving constant operator computes

`Q_t(z|s) = sum_m w_t(m|s) P0(z|m,s)`,

where `w_t(m|s)` is the empirical current motif frequency in segment `s` in that intervention branch. Every motif window in segment `s` then samples from the same `Q_t(.|s)`. This removes motif-specific local-state dependence while preserving expected one-site `P(Z|S)` for that current population by construction.

The actual branch uses the native motif-specific `P0(z|m,s)`.

For affinity reassignment, both branches use the exact archived deranged affinity matrix. For fixed-topology controls, both use the exact archived evaluation topology. For temporally unstable controls, both share the prospectively generated continuation-specific schedule.

## 5. Primary outcome

For every continuation:

`DeltaV_MP = V_actual - V_MP,constant`,

where each `V` is the mean population fitness across the 36 continuation generations.

Within each evaluation realization, average `DeltaV_MP` over the 64 new continuations. Then preserve the historical nesting hierarchy:

- average the two affinity-reassignment realizations only after continuation averaging;
- average the two topology-mismatch realizations only after continuation averaging;
- alternative-native = within-seed mean of A-native and B-native;
- alternative-cross = within-seed mean of A-under-B and B-under-A;
- stable-fixed reference = within-seed mean of A-native and B-native.

## 7. Primary inference

For each contrast:

- one paired contrast value per independent seed block (`n=20`);
- mean and median difference;
- 95% paired complete-seed-block bootstrap interval using 2,000 resamples;
- two-sided paired sign-randomization using 9,999 randomizations;
- Benjamini-Hochberg adjustment jointly across all six tests;
- positive and negative seed-block counts.

Analysis root seed: `2026100202`, with purpose-separated streams.

The unchanged historical pass criterion is:

`mean contrast > 0` **and** `BH-adjusted q < 0.05`.

No one-sided rescue test, contrast-specific retuning, or post-hoc multiplicity subset is permitted.
