# Round-2 MP evidence layer

This directory is the authoritative evidence layer for the current major revision.

`source_tables/` contains the frozen numerical evidence for the MP core sweep, corrected retained-information frontiers, first-99 diagnostic, six causal-specificity contrasts, independent affinity landscapes, marginal diagnostics, 65-setting screen, Stage C, and Stage D.

`scripts/` preserves the exact MP migration/diagnostic script bytes.

The primary intervention is the population-frequency-weighted probability-space marginal-preserving (MP) intervention. The historical pre-softmax affinity-averaging operator survives only as a secondary diagnostic comparator and is not used for primary causal estimates, retained-information frontiers, screening classifications, or inferential conclusions.

The current Supplement ends at Figure S6. Historical S7-S9 assets are not current publication evidence.
