# Round-2 MP scripts

These files preserve the exact source bytes from the frozen MP migration package.

- `make_mp_migration_figures.py` — MP migration figure/source-table generation
- `finish_figures.py` — figure finishing/synchronization
- `make_marginal_diagnostics.py` — marginal/adjacency diagnostic generation
- `regen_fig8.py` — targeted Figure 8 regeneration

Historical intermediate Supplement numbering inside these scripts is provenance only. The final Supplement contains Figures S1-S6.
