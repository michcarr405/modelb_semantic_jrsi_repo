# RC4 clean-room reproduction record

Status: **PASS**, with final-candidate rerun required after any repository change.

The clean-room workflow runs on GitHub-hosted Ubuntu 24.04 with Python 3.13.5 and installs only the declared locked dependencies plus the repository package.

The workflow:
1. verifies all 23 frozen MP migration source/script hashes;
2. verifies seven exact final-Supplement evidence hashes;
3. validates the frozen Round-2 numerical records;
4. validates the final Supplement reader/source records;
5. runs the complete repository test suite;
6. validates the historical result freeze;
7. compiles Round-2 scripts and validation code;
8. reproduces the empirical marginal-preservation diagnostic from archived Phase-4 states, frozen maps, and fixed continuation streams and compares the regenerated summary against the frozen summary;
9. regenerates representative MP publication figures from released source tables;
10. builds the public v2.0.0 release archive;
11. records environment and artifact hashes.

The empirical per-stream and per-population tables are deliberately generated by this workflow rather than duplicated as tracked derivative files. This preserves an auditable route from archived states/seeds/code to the final summary while keeping the repository source layer compact.
